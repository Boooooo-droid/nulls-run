# NULLS RUN

Unofficial, fan-made endless parkour runner for the [Nulls](https://x.com/nullsxyz) community. Not affiliated with Nulls. No wallet, no signup.

Pick one of five Nulls, press PLAY, and run the rooftops until the ERASE glitch virus catches you. Jump, slide, vault and climb. Grab memory fragments. Beat your best distance.

## Controls

- **Jump / vault / flip / climb:** swipe up, tap, click, Space, or Up. Swipe up again in the air to flip. Long jumps auto-flip; hard landings roll.
- **Slide:** swipe down, or Down / S. Swipe down as you land to go straight into a slide.
- **Pause:** P or Esc

## Characters

Sprites live in `assets/char1.png` … `assets/char5.png` (transparent PNGs, full color, full body). Billboards are `assets/billboard1.jpg` … `billboard3.jpg`. Swap those files to update art — no code changes needed.

Nulls name, wordmark, memory card and related art belong to Nulls; used here as fan art.
